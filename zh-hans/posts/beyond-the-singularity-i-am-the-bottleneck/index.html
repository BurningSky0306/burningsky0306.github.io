随笔

越过奇点之后，我是唯一的瓶颈

当前沿模型跨过个人的适应性奇点，阻碍任务推进的壁垒便从工具退回了我自己。在用不完的算力余量面前，我不得不从一问一答的交互中心抽身，尝试成为设计自主运行系统的那个人。

最近几个月以来，我基本拥有了有限但对我个人而言绝对充足的 Token。如何把这些 Token 物尽其用，成了困扰我的最高优先级问题。尤其是在半个月前把 Claude Pro 升级为 Max 之后，这种反差愈发清晰。我每天都要花大量时间去消耗额度，却始终只能用掉一半。

很长一段时间里，我习惯了等待更聪明的模型，习惯把停滞归咎于工具的边界。但自从 Opus 5.5 问世之后，在我个人能力保持缓慢提高的前提下，几乎我所有的任务都不再因为模型的能力瓶颈而停摆。前沿模型的发展对于我来说，已经抵达了一个「适应性奇点」。只要面对 Opus 5.5 及以上水准的模型，在我的任何任务场景下，阻碍或推迟任务往下推进的壁垒，都在我身上，而不再在模型。

为了推进某项任务，我需要花大量时间和模型反复 grilling，制定详细且我能够理解的计划，设计工作流架构并亲自测试运行。在整个任务链条里，最耗时的恰恰是我参与的那部分。如果要用 Claude 的订阅计划来类比个人的能力，或者更准确地说，在保证每一个 Token 都尽可能发挥作用而非空转浪费的前提下，用有效消耗的额度来丈量我对 Agent 的理解、运用和掌握程度，那么满负荷运转的我顶多也只能算作 Claude Pro 2.5x，我每天倾注大量心力与它交互，也只能触及 Max 额度的一半。倘若考虑劳逸结合因素，这个数字甚至要回落到 Claude Pro 1.7x。

回想去年下半年，谈及 AI 和 Agent 发展带给我最大的收获，我曾归结为观念进步、能力提高和提供自洽框架。那时的我欣喜于陌生领域的门槛被压缩到随时敢去碰一碰，欣喜于随时浮现的念头能立刻得到回复和延续，也受惠于它能将碎片化的知识迅速组织成自洽的图式。但回头再看，那三层收获之所以让我满足，是因为我彼时依然站在交互的中心，本质上都是一场一场的「双人问答」。思考终于有了高性能的即时反馈，可反馈的频率，依然受限于我自己的体力。

当我翻阅了 Anthropic 官方更新的几篇博文之后，发现前沿研究者很早就在尝试构建 long-running agents / always-on agents 了。那些探索照出了我停留在「Claude Pro 1.7x」的真正原因：只要我还执着于亲手审阅每一个中间步骤、亲自充当每一次循环的触发器，我就永远只能用肉身的线性时间去喂养指数级膨胀的算力。

我意识到，如今在提高 Agent 理解、运用和掌握能力这件事情上，最急切的已不再是打磨单次交互的技巧。我需要尽可能设计一个让 Agent 自主运行并自我迭代的系统。在新的分工里，我仅仅负责设计、评估和优化系统，而实际参与一线工作的全是 Agent 本身。从去年为思考拥有了即时反馈而雀跃，到如今在算力的余量面前审视自身的局限，我或许在这条道路上又往前迈得更远了。

只是，新的问题出现了，如若让 Agent 在没有我的昼夜里运转、将曾经用不完的额度顷刻吞没时，那个跑得比我的审视还要快的系统，又会在哪一层等着与我这位新的瓶颈重逢？
